NABULA

Der Bauplan ist fertiggestellt, der Bau hat begonnen.

Die nächste Generation von Discord-Bots ist da. Nabula wird von Grund auf neu entwickelt, um alle anderen Bots zu ersetzen und Ihren Servermitgliedern ein unterhaltsames, fesselndes und aktives Erlebnis zu bieten.

BOT-FUNKTIONEN // FEATURES & FÄHIGKEITEN

Alle Module sind über ein intuitives Web-Dashboard vollständig konfigurierbar.

  • 🔹 Temporäre Sprachkanäle

    [ ⚙️ IN ENTWICKLUNG ]

    Ermöglicht es Mitgliedern, dynamisch Sprachkanäle zu erstellen. Der Kanalinhaber kann Limits, Berechtigungen und Sichtbarkeit direkt über ein Kontrollpanel verwalten, das nach der Erstellung an den Sprachchat gesendet wird.

  • 🔹 Interaktive Willkommensbanner

    [ ⚙️ IN ENTWICKLUNG ]

    Erstellt personalisierte Banner mit Schaltflächen und GIFs. Jedes Detail, von der Vorlage bis zum Text, kann über das Dashboard angepasst werden.

  • 🔹 Dynamisches Leveling-System

    [ ⚙️ IN ENTWICKLUNG ]

    Ein fortschrittliches XP-Protokoll, das Aktivität belohnt. XP-Raten, Ränge und automatische Rollenzuweisungen werden vollständig im Dashboard konfiguriert.

  • 🛒 Nabula Shop & Economy

    [ ⚙️ IN ENTWICKLUNG ]

    Implementiert „NabCoins“ und einen Shop für digitale Güter. Erstellen und verwalten Sie Gegenstände, Preise und Inventar direkt über das Dashboard.

  • 🔹 Holodeck // Mini-Spiele

    [ ⚙️ IN ENTWICKLUNG ]

    Steigert die Server-Interaktion mit integrierten Spielen. Aktivieren Sie Spiele und legen Sie Einsatzlimits für NabCoins über das Dashboard fest.

  • 🔹 GUARDIAN // Smarte Moderation

    [ ⚙️ IN ENTWICKLUNG ]

    Ein autonomer Moderations-Agent mit einem adaptiven Wortfilter und Anti-Spam. Alle Regeln und Filter werden zentral im Dashboard verwaltet.

  • 💠 And many more modules are on the way...

    [CLASSIFIED]

    The features listed are just the beginning. We're building some groundbreaking new systems that are still under wraps. // Stay tuned. It's going to be wild.
